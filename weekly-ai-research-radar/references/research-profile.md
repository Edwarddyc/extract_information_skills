# Research Profile

Use this profile to allocate attention and judge research impact. It is a priority map, not a quota.

## A. Agent Framework Engineering

Default attention share: 35-40%.

Focus:

- Agent harness architecture, request lifecycle, context and state management, tool execution, routing, recovery, observability, and plugin ecosystems.
- External comparison of runtime abstractions across PydanticAI, Google ADK, Microsoft Agent Framework, OpenHands, Letta Code, and trial sources such as Strands Agents.
- Cross-framework standards and evidence from A2A, OpenTelemetry GenAI semantic conventions, and MCP specification changes.
- Mechanism studies of sandboxing, session and memory models, durable workflows, tool policy, recovery, telemetry, and agent-to-agent communication.

High-value changes include architecture rewrites, new execution or memory abstractions, protocol changes, reproducible performance results, important releases, and failure analyses. Routine integrations and marketing launches are low value unless they reveal a reusable design pattern.

Treat this axis as an external-comparison and mechanism-research layer, not a second changelog. Priority Watch projects may appear only as comparison targets or supporting citations; do not create a standalone axis item that repeats an Anthropic, OpenAI, Hermes, Pi, DeepSeek Harness, Agno, LangChain, or Langfuse update already reported above.

Every retained framework note must state a research question, mechanism finding, comparison or boundary condition, and explicit data sources. Prefer two or more independent primary artifacts. A one-source mechanism deep dive is allowed only when it uses at least two artifact types such as code plus documentation, release notes plus tests, or specification plus reference implementation.

## B. Agent Evaluation and Token Economics

Default attention share: 25-30%.

Focus:

- Evaluation validity, benchmark design, judge reliability, contamination, trajectory and tool-use evaluation, cost-quality-latency tradeoffs, inference-time scaling, multi-agent allocation, and token budgets.
- Evidence that connects token expenditure to capability, robustness, coordination, or self-improvement.

Prefer papers with clear task definitions, baselines, ablations, cost reporting, released artifacts, and failure cases. A new leaderboard score without evaluation-method insight is weak.

## C. AI Self-Evolution and AGI Philosophy

Default attention share: 15-20%.

Focus:

- Recursive improvement, self-reflection, self-play, curriculum generation, autonomous research, persistent identity or emotion mechanisms, intrinsic motivation, agency, and the boundary between optimization and genuine adaptation.

Require stronger epistemic discipline here. Separate empirical mechanism, theoretical proposal, philosophical interpretation, and metaphor. Philosophical work is valuable when it sharpens a testable distinction or changes system design.

## D. AI Products and Platforms

Default attention share: 15-20%.

Focus:

- AI-native research, content, intelligence-analysis, and document-production systems.
- Product architecture, human-in-the-loop workflow, provenance, evaluation, distribution, pricing or usage constraints, and evidence of actual adoption.

Prioritize product changes that expose a transferable workflow or infrastructure choice. Ordinary feature announcements are low priority.

## Cross-Axis Questions

Actively look for:

- A framework mechanism that changes evaluation design or token allocation.
- An evaluation result that invalidates a product or architecture assumption.
- A self-evolution mechanism that can be operationalized in a harness.
- Product usage evidence that challenges a theoretical model of agents.

## Personal Impact Test

An item has high personal relevance when it can do at least one of the following:

- revise an existing Hermes/Harness architecture map;
- add or invalidate a dimension in the agent evaluation system;
- supply evidence for Token Economics;
- turn a self-evolution idea into a mechanism or experiment;
- change the design of an AI-native content, research, or document platform;
- justify a durable addition to a long-form research document.
